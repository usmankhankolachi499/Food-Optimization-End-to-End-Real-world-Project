Platform capabilities

Everything from SRS, ready to demo

Web app built around user auth, orders, tracking, assignment, analytics and more.

User management & roles

Customers, Delivery Partners and Admin with role-based access control, secure sessions and CSRF protection.

Order & restaurant management

Menu catalogues, cart, checkout, order lifecycle, cancellation rules and customer profiles.

Live GPS tracking

Real-time partner location on Leaflet maps with trail history, auto-refresh and JSON API endpoints.

Route optimization

Nearest-neighbour pathing, pickup-before-drop for batches, traffic-aware ETAs and configurable parameters.

Smart order assignment

Assigns the nearest available partner while considering workload and delivery radius, with manual/admin override.

Analytics, reports & alerts

Delivery time, peak hours, partner performance, revenue trends, CSV exports and in-app notifications.

Data & integrations

Built to plug into your ML pipeline

The web layer stays fully functional on its own. If you add a ml.predictor module, ETAs and partner ranking switch to it automatically. Location logs can also mirror to MongoDB.

  • SQL Server (T-SQL) storage via pyodbc — SQLite fallback included
  • Optional MongoDB store for high-volume tracking
  • Rest/JSON API for maps and clients
  • CLI tools: flask init-db, flask seed-demo, flask create-admin
